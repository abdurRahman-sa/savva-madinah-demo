# Savva Cafe Demo — сгенерированные позиции меню

Эта папка — единственный источник рабочих AI-изображений для карточек меню демо-сайта.

Продукты сгенерированы и скомпонованы на основе реальных фонов кафе Savva из предоставленных пользователем кадров. Люди, надписи, элементы видеоплеера и посторонняя посуда удалены. Эти изображения нельзя выдавать за реальные фотографии продукции кафе.

Файлы названы техническими идентификаторами, которые используются в `version-2/src/data/cafe.ts`. В `version-2/src/assets/menu/` находятся только относительные символические ссылки на эти файлы; физических дублей там нет.

Подготовленные чистые фоны для следующих генераций:

- `background-cream-table.png` - светлый стол у кремового дивана;
- `background-window-table.png` - круглый каменный стол у окна;
- `background-plant-table.png` - светлый стол с растением.
